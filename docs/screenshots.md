# Screenshots

No screenshots are included in this deliverable — this sandbox has no
browser/display to capture real screenshots from, and including
placeholder/mockup images would risk being mistaken for actual UI
output. Once run in a real browser (see root README.md for exact
commands), the following views are available and worth capturing for a
demo/portfolio:

1. Main IDE (editor + pipeline + tabs)
2. Tokens tab (real token stream table)
3. AST tab (collapsible real parse tree)
4. Symbols tab (declared identifiers derived from real AST output)
5. Dependencies tab (real dependency list + evaluation order)
6. LLVM IR tab (real generated IR, verified/function/block counts)
7. Runtime tab (real program stdout + exit code)
8. Error case (e.g. the "Undefined Function" example) showing the
   pipeline stopping at Semantic Analysis with later stages skipped
